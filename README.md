# Java Assignment 2 — Pet Selector

A Java Swing desktop application with five radio buttons (Bird, Cat, Dog, Rabbit, Pig). Selecting an option updates the pet illustration and displays a message box confirming the selection.

## Requirements
- JDK 8 or later
- NetBeans, IntelliJ IDEA, or another Java IDE (optional)

## Run from the terminal
1. Open a terminal in the `src` folder.
2. Compile: `javac PetSelector.java`
3. Run: `java PetSelector`

## Run in NetBeans
1. Create a new **Java Application** project named `PetSelectorAssignment`.
2. Copy `src/PetSelector.java` into the project's source package. If NetBeans creates a package declaration, either remove that package declaration or add the same package declaration at the top of this file.
3. Run `PetSelector.java`.

## What to test
- The app starts with Pig selected.
- Selecting each of Bird, Cat, Dog, Rabbit, and Pig updates the illustration and label.
- A message box appears after each selection.
